# Source analysis: Audit Practice Manual: The Fundamentals of an ISA Audit (workshop, 18-19 August 2026)

Model of the review expected in step 2 of the skill. Generated from `assets/apm_content.json`.

## Summary
The source is a two-day training deck on the Audit Practice Manual (APM). The APM is a structured set of audit programmes, checklists and example documents. It is built to produce an ISA-compliant file for a straightforward, single-entity audit using a wholly substantive approach. The APM describes itself as guidance, not regulation, so it does not bind a firm on its own. A firm that adopts it needs its own approved policies that say who must do what, by when, and with what evidence. This manual turns the APM's method into that layer of firm policy.

## Strengths
- A clear risk > response > evidence > conclusion > opinion chain, with each step tied to specific ISA paragraphs.
- Practical tests a reviewer can apply: 'a heading is not a risk', the four-question working paper test, 'one error is never just one error'.
- A fixed file reference system (Ac/C-O/Ab/Aa/A/B), so any judgement can be found without asking the engagement team.
- Quantified sampling guidance: five approaches, transaction sample table, substantive formula with a worked example, controls frequency table.
- Covers the standards effective 15 December 2026 (ISA 240 Revised, ISA 570 Revised 2024, 'publicly traded entity') ahead of the first affected opinions.
- Treats acceptance and capacity as quality objectives (ISQM 1), not commercial decisions.
